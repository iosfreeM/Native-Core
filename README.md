# Native Core

Приложение для iOS, которое редактирует **MobileGestalt** и **PosterBoard** прямо на устройстве.

## Возможности

### MobileGestalt
- Dynamic Island
- Always-On Display и AOD Vibrancy
- Boot Chime
- Лимит зарядки 80%
- Tap to Wake
- Stage Manager
- Apple Pencil
- Action Button
- Apply / Revert Tweaks и Respring

### PosterBoard
- Импорт паков обоев `.tendies` (до 5 паков за раз)
- Apply All, Reset PosterBoard, Open PosterBoard
- Обои iOS 26+

## Требования
- iOS 27 Release и выше (MobileGestalt)
- iOS 26+ (обои .tendies)

## Установка
1. Скачай `Native_Core.ipa` из раздела [Releases](../../releases).
2. Установи через AltStore, SideStore, Sideloadly или другой сайдлоадер.

## Важно
- Применяй твики на свой риск. Перед изменениями лучше сделать резервную копию.
- Revert Tweaks и Reset PosterBoard возвращают исходное состояние.
- Если импортируешь больше 15 паков, могут быть проблемы со стабильностью.

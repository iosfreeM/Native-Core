# Native Core

Приложение для iOS, которое редактирует **MobileGestalt**, **CacheExtra** и **PosterBoard** прямо на устройстве, без ПК.

## Версии

| | Native Core | Native Core Enhanced |
|---|---|---|
| Минимальная iOS | 14.0 | 26.0 |
| Размер | ~0.3 МБ | ~9.8 МБ |
| Языки | RU, EN, UK, AR, KO, TR, VI | RU, EN |
| Bundle ID | `com.native.core` | `com.native.core.enhanced` |
| Вкладки | Native Core, PosterBoard, Настройки | Tweaks, Extra, Backup, Sandbox, Log |

Обе версии можно ставить одновременно: у них разные Bundle ID.

## Native Core

**MobileGestalt**
- Dynamic Island: выбор модели и позиции
- Always-On Display и яркость AOD
- Звук загрузки
- Лимит заряда 80%
- Tap to Wake, Stage Manager, Apple Pencil, Action Button
- SOS при столкновении, отключение параллакса обоев
- Apple Intelligence и Siri AI (регион США)
- Подмена версии iOS и устройства для AI
- Режим iPadOS (экспериментально)
- Режим security-исследователя и режим демонстрации в магазине
- Редактор CacheExtra
- Применить / откатить твики, Respring

**PosterBoard**
- Импорт паков `.tendies` (до 5 за раз)
- Apply All, Reset PosterBoard, Open PosterBoard, Explore Wallpapers

**Настройки**
- Respring, журнал, выбор языка, запись на месте

## Native Core Enhanced

Расширенная версия с отдельными вкладками.

**Tweaks**
- Device Artwork: Subtype и Custom Device Name
- Dynamic Island, Always-On Display, AOD Vibrancy, Wallpaper Parallax
- Charge Limit Menu, Boot & Shutdown Chime
- Liquid Glass Low-Performance Mode (включить / отключить)
- iPhone 16 Camera Control, Action Button, Collision SOS, Pulse Width Modulation
- Eligibility: Security Research Device Mode, Disable Region Restrictions, Apple Intelligence
- iPadOS: Allow iPad Apps, Apple Pencil Settings, iPadOS Mode
- Internal: Internal Storage View, Internal Features, Apple Internal Install
- Persist after reboot (запись на месте)

**Extra**: редактор CacheExtra, любые ключи и значения.

**Backup**: оригинальный бэкап MobileGestalt, снимок при каждом Apply, ручной Back Up Now.

**Sandbox**: App Group, Target Path, Consume / Release Sandbox Extension, Get Paths.

**Log**: консоль с журналом операций.

## Требования
- MobileGestalt: iOS 27 Release и выше
- Обои .tendies: iOS 26+
- Enhanced: iOS 26+

## Установка
Обе версии устанавливаются через сайдлоад.
1. Скачай нужный `.ipa` из раздела [Releases](../../releases).
2. Установи через AltStore, SideStore, Sideloadly или другой сайдлоадер.

## Важно
- Твики могут сломать функции или привести к softbrick. Применяй на свой риск.
- Перед изменениями сохраняется оригинальный бэкап MobileGestalt.
- Revert и восстановление из бэкапа требуют полной перезагрузки устройства.
- Используй только на своих устройствах.
